# Learning Objectives

## Objective {N}: {Short, skill-named title, e.g. "Develop confidence in public speaking"}

**Purpose — Why this matters:** {1–2 sentences on why this skill/knowledge matters
beyond this one course or institution. Use a Bloom's-Taxonomy verb
(understanding / applying / analyzing / synthesizing / judging / evaluating /
creating / inventing) where the objective is cognitive; for affective or
psychomotor skills — confidence, delivery, collaboration — plain language naming
the skill is fine. Bloom's is a tool for clarity here, not a hard requirement.}

**Task — What you will do:** {The concrete activities and sequence across the
term that build this skill — not just the final deliverable. Name how students
track their own progress if relevant (e.g., pre-/post- reflections), and how
feedback loops into a revision or next attempt.}

**Criteria — How you'll know you're succeeding:** {The observable characteristics
of growth/success for this objective, specific enough that a student can
self-assess against it. If multiple concrete examples of stronger vs. weaker
work exist elsewhere in the course (a rubric, reviewed samples), point to them
here. Note how this objective connects to grading/weighting, or where that's
covered elsewhere in the syllabus if not here.}
