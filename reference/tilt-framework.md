# TILT Framework — Reference

Source: Mary-Ann Winkelmes, "Transparent Assignment Design Template for Teachers" and "Checklist for Designing Transparent Assignments" (TILT Higher Ed, tilthighered.com, 2012–2026). Condensed here for reuse; see `context/TILT Framework for Teachers.pdf` and `context/Checklist for Designing Transparent Assignments.pdf` for the originals.

TILT ("Transparency in Learning and Teaching") holds that student learning and equity improve when instructors make explicit, in writing, on every significant assignment: **why** it's being asked (Purpose), **what** to do (Task), and **how it will be judged** (Criteria). The mechanism isn't the writing itself — it's that transparent framing lets students access the same "hidden curriculum" knowledge about how to succeed that already-advantaged students tend to pick up elsewhere.

## The three sections

### PURPOSE
Define learning objectives in language students recognize as benefiting them — not just "why the instructor assigned this" but why it matters beyond this one artifact.

- **Skills**: name 1–2 skills for introductory students (more for advanced students who can hold a metacognitive focus on multiple skills at once). Use Bloom's Taxonomy verbs, ordered simple → complex: *understanding* basic knowledge/methods → *applying* them to an unfamiliar-but-similar context → *analyzing / synthesizing / judging / evaluating* to select the best solution → *creating / inventing* a new interpretation, product, or theory.
- **Knowledge**: name the specific disciplinary concepts/content the assignment builds familiarity with.
- Connect explicitly to institutional learning outcomes and to students' lives beyond the course/institution (the field, professional practice generally).

### TASK
Define what students actually do, not just what they produce.

- List concrete actions/guidelines and a recommended sequence.
- Name mistakes to avoid.
- Confirm equitable access to any resources the task requires.
- If information is deliberately withheld for pedagogical reasons (productive struggle), say so explicitly and frame it as purposeful: *"The purpose of this assignment is for you to struggle and feel confused while you invent and test your own approach to the problem…"* — this protects students' sense of belonging (ambiguity reads as "I don't belong" if unexplained, and as "this struggle is expected and valuable" if named).
- Where relevant, include Bloom's-Taxonomy "question cues" (Anderson & Krathwohl revision) so task verbs match the cognitive level named in Purpose.
- Gather student feedback on how they perceive the task before finalizing; revise the prompt in response ("TILTed conversation").

### CRITERIA
Define what the finished product looks like — before students start working, not just at grading time.

- Provide multiple concrete examples spanning excellent / adequate / unacceptable quality, ideally analyzed collaboratively with students before they begin.
- Build a checklist of characteristics of successful work (can be co-created with students from their analysis of the examples); this checklist doubles as a peer-feedback tool.
- State whether/how the work is graded and how it factors into the course grade.
- Build in a reflection step after grading: ask students what they'd change about their process next time — this is where the learning-strategy payoff compounds.

## Compact self-audit checklist

Use this to check a drafted assignment before finalizing (derived from the full TILT Checklist for Designing Transparent Assignments):

- [ ] Due date(s) stated at the top
- [ ] A section literally labeled "Purpose" exists
- [ ] Purpose states which skills this practices and why they matter beyond this assignment/course
- [ ] Purpose uses Bloom's-Taxonomy language (understanding / applying / analyzing / synthesizing / judging / evaluating / creating / inventing)
- [ ] Purpose names the specific disciplinary knowledge/content involved
- [ ] A section literally labeled "Task" exists
- [ ] Task defines concrete actions/activities, not just the deliverable
- [ ] Task lists guidelines and/or a recommended sequence
- [ ] Task uses question cues matching the Bloom's level named in Purpose
- [ ] A section literally labeled "Criteria for Success" exists
- [ ] Criteria define the characteristics of the finished product
- [ ] Criteria give multiple specific examples of what those characteristics look like in practice
- [ ] A plan exists to analyze a good-work example with students before they start (even if not written into the handout — can be a class-discussion note-to-self)
- [ ] A plan exists to help students distinguish excellent vs. adequate work before they start
- [ ] Criteria include either (a) a checklist + real-world examples of varied quality, or (b) an explicit rationale for withholding that information as productive ambiguity
- [ ] A plan exists for students to use a checklist for peer feedback
- [ ] Criteria state whether/how this is graded and its weight in the course grade
- [ ] A plan exists for post-grade reflection on what students would change next time

If an item is "no," that's not necessarily a defect — flag it and ask the instructor whether it's an intentional omission (e.g., deliberate productive-struggle design) or a gap to fill.
